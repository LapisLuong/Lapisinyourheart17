# FallSense for macOS

Download `FallSense_macOS.zip` using GitHub's **Download raw file** button.

The ZIP contains two QuickTime-friendly 1080p60 H.264/AAC videos, editable Remotion source, reference documents, and macOS launch scripts. Extract it, then open `FallSense/Videos` to watch. No Node installation is needed to watch the videos. See `FallSense/MACOS.md` to edit or render.

Music is included only in the 43-second opening. The full show is 224 seconds. Files were checked by full decoding on Linux; native macOS 27 has not been tested.
