# FallSense V4 — smooth 3D intro + editable PowerPoint

**Download `FallSense_V4_macOS_PPT.zip` (about 24 MB)** with GitHub's Download raw file button. No workspace artifact service is needed.

Extract the ZIP, open `FallSense_V4/Videos` to play the MP4 in QuickTime. Open `FallSense_V4/Slides/FallSense_Academic_13_Slides_Editable.pptx` in PowerPoint, or its preview PDF in Preview. Node.js is only needed to edit/render video source.

The bundle contains the 43s 1080p60 H.264/AAC film, new 13-slide native editable PPTX with notes, PDF preview, matching end PNG, source and audit reports. Source is also committed as ordinary files under `/source-v4` on this branch.

V4 changes the previous shot-local resets to global C2 position paths and quaternion camera interpolation. Repeat-render pixel comparisons, full film decode/timestamps, blackdetect, audio checks, PPTX structure and LibreOffice PDF rendering passed; details and limits are in the reports.
